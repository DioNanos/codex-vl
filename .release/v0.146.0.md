# Codex VL 0.146.0

This release record tracks the final upstream OpenAI Codex `rust-v0.146.0`
release while retaining the Codex VL workflow layer.

## Preserved fork contracts

- Goal and loop state remain persisted separately, with legacy Vivling loop
  migration reconciliation before normal state migration.
- `/vivling`, `/vl`, `/loop`, and the TUI's local-workflow boundaries remain
  available, and MCP startup keeps its bounded tools-list retry.
- Provider-specific `namespace_tools` configuration remains authoritative.
- Managed updates and standalone installers stay on the fork-owned package and
  release channels; no upstream installer is fetched or executed.

## Release gate

This source record documents the checks required before publication. The npm
registry and GitHub Releases are authoritative for live publication status.
Publication requires a clean feature-register review and sanitized package
verification.

## Feature-register audit

- **Core goal lifecycle:** upstream goal lifecycle and state changes are
  retained; no fork behavior bypasses upstream completion or state boundaries.
- **GoalStore and state boundary:** upstream SQLite paths are used for normal
  state, while the fork preserves legacy/Android Vivling loop reconciliation
  before regular migration.
- **Loop jobs and `manage_loops`:** upstream loop persistence remains intact;
  session-scoped VL controls and migration numbers are covered by targeted
  state and TUI tests.
- **Vivling runtime and delegation:** the fork-owned lifecycle FSM and its
  bounded local runtime remain isolated from upstream control flow and pass
  their targeted lifecycle tests.
- **VL UI boundaries:** `/vivling`, `/vl`, `/loop`, and local-workflow UI
  paths are retained without changing the upstream TUI state contract.
- **Remote-control and app-server:** upstream app-server integration is
  retained while managed updates and standalone installers remain on the
  fork-owned, fail-closed channel.
- **Fork identity and release safety:** package identity stays
  `@mmmbuto/codex-vl`; publication requires a separate sanitized artifact gate
  and explicit authorization.
