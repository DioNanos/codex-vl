# Codex VL 0.160.0-vl.1

Fork release on the upstream OpenAI Codex `rust-v0.160.0` base.

## Contents

- Mapped `codex-package` npm layout (`bin/`, `codex-path/`, `codex-resources/`,
  `codex-package.json` with `variant: "codex-vl"`) with the `-vl` managed-daemon
  isolation (packages, state directory, control socket) and Android as a
  first-class platform target.
- `bin/codex-exec.js` resolves the mapped platform layout in addition to the
  legacy `vendor/<triple>/codex/codex` one.
- The packaging workflows compile bubblewrap from a neutral source directory,
  keep the cargo target dir outside the CI checkout, and refuse a tarball that
  embeds the runner checkout path, deriving the repository name from the CI
  context.
- `npm pack --json` is accepted in both the npm 12 (object) and the npm ≤11
  (array) shapes.

## Verification

- The release branch sits on the audited merge of `rust-v0.160.0` (fork
  feature register applied, release gate green) plus the packaging and
  launcher commits above.
- Packaging builds run on the public GitHub workflows; the local smoke on the
  archived artifacts is documented in the release report, out of this tree.
