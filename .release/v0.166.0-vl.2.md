# Codex VL 0.166.0-vl.2

Fork release on the upstream OpenAI Codex `rust-v0.166.0` base.

## Contents

- Security: V8 rebuilt with the backport of the fix for CVE-2026-85046 (type
  confusion in `Array.prototype.sort`) on every published platform (Linux x64,
  Linux arm64 musl, Android arm64, macOS arm64 via postinstall); the V8
  archives come from the `rusty-v8-v152.2.0-vl1` release, pinned by checksum.
- Packaging: every non-Windows consumer, CI and the source package build
  including archive overrides, refuses a V8 archive without the backport
  marker.
- Fixes: `/vivling help` now lists `layout`, `loop-strategy` and `memory`.
- Docs: added the Vivling command reference (`docs/vivling_commands.md`),
  linked from the README.

## Install

```bash
npm install -g @mmmbuto/codex-vl@latest --allow-scripts=@mmmbuto/codex-vl
```

`@latest` points to this release once it is promoted; to pin it, use
`@mmmbuto/codex-vl@0.166.0-vl.2`. The platform builds are published as
`@mmmbuto/codex-vl@0.166.0-vl.2-<platform>` (`linux-x64`, `linux-arm64`,
`android-arm64`, `darwin-arm64`); the main package selects the right one.
The macOS arm64 package is built from source during installation.

## Verification

- The release branch sits on the merge of `rust-v0.166.0` (fork feature
  register applied) plus the security and packaging commits.
- Packaging builds run on the public GitHub workflows; the local smoke on the
  built archives is documented in the release report, out of this tree.
