# Codex VL 0.166.0-vl.1

Fork release on the upstream OpenAI Codex `rust-v0.166.0` base.

## Contents

- Upstream `rust-v0.166.0` merged with the fork feature set intact: Vivling,
  `/loop` and `manage_loops`, the VL UI, fork identity, the Termux and Android
  compatibility guards and the `-vl` managed daemon. Upstream highlights:
  keyboard-driven transcript selection with word, line, and page motions plus
  integrated search, Markdown rendered consistently in async questions,
  choices, answers, and transcript replies, GPT-6.1 Terra in the bundled,
  Vertex AI, and Bedrock model catalogs, `codex queue --resume` for unloaded
  threads, clearer safety-block explanations with selectable safer follow-up
  prompts, and `codex doctor --network-only`. Upstream fixes include
  acknowledged approval and permission settings preserved when resuming or
  forking threads, local image attachments preserved when restoring killed
  composer text, standalone release cleanup on macOS, spawned descendant
  threads restored when unarchiving their parent, app-server thread startup
  and shutdown races fixed with prompt runtime release, TUI reconnection
  recovery including offline `/quit` and `/exit`, and reasoning-token
  accounting preserved across resume and fork. Upstream chores: Bazel switched
  to source-built V8 with target-matched Rust bindings, the standalone
  executor shipped in canonical release packages, and toolchains standardized
  on Node 24.22.1 and Rust 1.95.0.
- Cleanup: clippy findings in fork code fixed or justified and the touched
  files reformatted with rustfmt (no behavior changes).

## Install

```bash
npm install -g @mmmbuto/codex-vl@latest --allow-scripts=@mmmbuto/codex-vl
```

`@latest` points to this release once it is promoted; to pin it, use
`@mmmbuto/codex-vl@0.166.0-vl.1`. The platform builds are published as
`@mmmbuto/codex-vl@0.166.0-vl.1-<platform>` (`linux-x64`, `linux-arm64`,
`android-arm64`, `darwin-arm64`); the main package selects the right one.
The macOS arm64 package is built from source during installation.
