# Codex VL 0.165.0-vl.1

Fork release on the upstream OpenAI Codex `rust-v0.165.0` base. It also carries
the work staged for the 0.163 and 0.164 lines, which were never published: its launcher
environment fixes ship here for the first time.

## Contents

- Upstream `rust-v0.165.0` merged with the fork feature set intact: Vivling,
  `/loop` and `manage_loops`, the VL UI, fork identity, the Termux and Android
  compatibility guards and the `-vl` managed daemon. Upstream highlights:
  built-in Google Cloud Vertex AI provider (`model_provider = "gcp"`), GPT-6.1 Terra
  in model catalogs, repository filter in the session picker and directory grouping
  in the agent command center, experimental attached thread forks in the app-server API,
  reasoning effort changes enabled by default, and memory v2 enabled by default for fresh
  profiles with external-agent memory imports. Upstream fixes include fresh TUI sessions
  honoring server approval reviewer defaults, TUI preferences remaining editable with
  invalid execution settings, dropped response futures cancelling remote MCP tool requests,
  interrupts and Plan mode preventing queued agent messages from resuming work, non-retryable
  model-not-found errors preserved, and marketplace URL userinfo backslash gap closed.
- Launcher: stop rewriting `LD_LIBRARY_PATH` on Android; the native binary
  resolves its shared libraries via `$ORIGIN` in DT_RUNPATH, preserving
  caller-provided paths.
- Launcher: scrub launcher-private CODEX metadata from external child processes
  on Android across shell/exec, MCP stdio servers, hooks, cloud tasks, plugins,
  worktree, and tools boundaries; caller-provided loader variables are
  preserved.
- Dependencies: refreshed security audits with webpki and ctutils updates,
  accepted upstream advisories ignored in deny.toml, and aligned process
  utilities formatting.
- Tests: coverage for launcher child environment policies and boundary
  sentinels.

## Install

```bash
npm install -g @mmmbuto/codex-vl@latest --allow-scripts=@mmmbuto/codex-vl
```

`@latest` points to this release once it is promoted; to pin it, use
`@mmmbuto/codex-vl@0.165.0-vl.1`. The platform builds are published as
`@mmmbuto/codex-vl@0.165.0-vl.1-<platform>` (`linux-x64`, `linux-arm64`,
`android-arm64`, `darwin-arm64`); the main package selects the right one.
The macOS arm64 package is built from source during installation.

## Verification

- The release branch sits on the merge of `rust-v0.165.0` (fork feature
  register applied) plus the release commit.
- Packaging builds run on the public GitHub workflows; the local smoke on the
  built archives is documented in the release report, out of this tree.
