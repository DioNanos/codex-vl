# [0.147.2] - 2026-08-10

Fork-only patch release on top of the upstream OpenAI Codex `rust-v0.147.0`
stable release. Upstream has no `rust-v0.147.2`.

## Fixed

- **Code mode ran without the V8 sandbox on every platform.**
  `code-mode-runtime` depends on the `v8` crate with `v8_enable_sandbox`, and the
  v8 build script derives the prebuilt's name from the enabled features. Setting
  `RUSTY_V8_ARCHIVE` overrides that name without checking it, and the packaging
  pointed it at the plain prebuilt. Everything compiled, linked and ran, code
  mode worked, and `v8::V8::is_sandbox_enabled()` was `false` — with no error, no
  warning and nothing at runtime that said so. Every 0.147.0 and 0.147.1 install
  is affected.

  All packages now link the `ptrcomp_sandbox_release` profile, pinned by
  checksum, and each build verifies the archive it actually linked by decoding
  what `v8__V8__IsSandboxEnabled` returns rather than trusting the file name.

## Added

- **An Android prebuilt with the sandbox.** No such archive existed anywhere, so
  V8 is now built from source for `aarch64-linux-android` in CI, with the
  sandbox feature, and published with its checksums.
